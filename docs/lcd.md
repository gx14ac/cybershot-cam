### 選ぶときの条件

- ドライバ IC が ST7735（R でも S でも可）。ST7789 と ILI9341 は不可。
- 解像度が 128×160。1.44 インチ（128×128）と 0.96 インチは不可。
- SPI 接続。
- SD スロットはあってもなくてもよい。付いているピンは使わない。

## 配線（WINGONEER のピン名）

ピンの並び順は KKHMF と違うが、つなぐ先は同じ。

| 液晶 | ボード | ガイドでの名前 |
| --- | --- | --- |
| GND | GND | GND |
| VCC | 3V3 | VCC |
| SCL | GPIO 47 | SCK |
| SDA | GPIO 45 | SDA |
| RES | GPIO 21 | RESET |
| DC | GPIO 14 | A0 |
| CS | GPIO 43 | CS |
| BL | 3V3 | LED |

ファームが指定しているのは CS / DC / RST と SPI の SCK / SDA の5本だけ（`Adafruit_ST7735 tft(&tftSPI, TFT_CS, TFT_DC, TFT_RST)`）。この5本をつなげば、どの ST7735 モジュールでも動く。

## 初期化の癖

この商品のレビュー（2026-11-15）に、同じ組み合わせ（ESP32-S3 + Adafruit_ST7735 ライブラリ + ハードウェア SPI）での報告がある。

| 設定 | 結果 |
| --- | --- |
| `INITR_BLACKTAB`（今のコード） | 色は正しい。右端と下端にノイズが残る |
| `INITR_GREENTAB` | 端まで正しく表示される。赤と青が入れ替わる |

レビューを書いた人は、`GREENTAB` にしたうえで、色の定数（RED と BLUE、YELLOW と CYAN）と `color565` の引数を入れ替えて解決した。

このカメラではファインダーにカメラ映像をそのまま描くので、色の定数を入れ替えるだけでは映像の色が直らない。届いたら次の順で試す。

1. まず `INITR_BLACKTAB` のまま表示を見る。端のノイズが目立たなければ、それで終わり。
2. ノイズが気になるときは `INITR_GREENTAB` にする。そのうえで `setRotation()` のあとに MADCTL を RGB の並びで送り直して、赤と青を液晶側で直す。

## 電圧

レビューには「3.3V だと色が薄い」というものと「Raspberry Pi Pico の 3.3V で問題なかった」というものがある。このカメラでは 3V3 から取る。白っぽく見えたら、そのときに考える。
