    01配線表

    部品部品側の端子つなぐ先つなぎ方手順

    このボードの 3V3 と GND は1本ずつしかないので、「まとめ点」で分けます。まとめ点は、何本かの線をより合わせてはんだで1つにし、熱収縮チューブで覆ったものです。はんだが不安なら、レバー式のワイヤーコネクター（WAGO 221 など）でも作れます。

    02部品

    • Freenove ESP32-S3 WROOM CAM（N16R8、OV2640 付き）
    • 1.8インチ SPI 液晶 ST7735（128×160）
    • ジョイスティック KY-023
    • 丸い押しボタン（モーメンタリ）シャッター
    • 5mm 赤色 LED と 100Ω 抵抗 フラッシュ
    • microSD カード
    • 18650 電池と電池ホルダー
    • TP4056（保護回路付き、USB-C）充電
    • MT3608 5V への昇圧
    • ロッカースイッチ 電源
    • メス-メスのジャンパー線
    • テスター 5.0V の調整に使う

    ほかに、はんだ（0.6〜0.8mm）、熱収縮チューブ、データ通信できる USB-C ケーブルがあると安心です。電池で動かしていて再起動するときは、MT3608 の出力側に 220〜470µF（10V 以上）の電解コンデンサを足してください。

    03はんだ付けが初めての人へ

    1か所の流れ

    • こての温度は 320〜350℃ くらい。
    • こて先を、パッド（基板の金属部分）と線の両方に同時に当てて 2〜3 秒温める。
    • こて先ではなく、温めた部分にはんだを当てて溶かす。量は米粒くらい。
    • はんだを離してから、こてを離す。冷えるまで 3 秒ほど動かさない。
    • 山の形でツヤがあれば成功。丸い玉やくすんだ色なら温め直す。

    この作業で気をつけること

    • TP4056 と MT3608 の端子は間隔が狭いので、隣とはんだでつながっていないか必ず見る。
    • 線の先は 3〜4mm むいてより合わせ、先に少しはんだをなじませておく（予備はんだ）。
    • 電池は、はんだ付けがすべて終わってから入れる。
    • はんだ付けしたところは、熱収縮チューブかビニールテープで覆う。
    • ジャンパー線を半分に切ると、片側がメスのまま残る「はんだ用の線」になる。

    04プログラムとの照合

    ピン番号は src/main.cpp と Freenove 公式のピン配置図で照らし合わせています。

    項目結果内容
    カメラのピン一致XCLK 15、SIOD 4、SIOC 5、D0〜D7、VSYNC 6、HREF 7、PCLK 13 の全14本が、公式ピン配置図の CAM_ 表記と一致（main.cpp:61-76）。作者のボードは GOOUUU 製 V1.3 だが、同じ系統のピン配置。
    microSD一致CLK 39、CMD 38、D0 40 の1ビットモード。ボード上のスロットをそのまま使う（main.cpp:2851-2852）。
    シャッターとジョイスティックの押し込み抵抗不要内部プルアップを使っている（main.cpp:2830、2833）。GND とつなぐだけで動く。
    ジョイスティック（GPIO 1、2）問題なしADC1 なので Wi-Fi 使用中でも読める。1000 未満と 3000 超えで判定する（main.cpp:3381-3386）ので、電源は必ず 3.3V。
    PSRAM / Flash一致platformio.ini の qio_opi と 16MB は N16R8 に合う。
    ビルド成功PlatformIO 6.2.0 で RAM 30.7%、Flash 40.1%。ライブラリは ST7735 1.12.0、GFX 1.13.0、JPEGDEC 1.8.5 に固定。
    GPIO 45（液晶 SDA）問題なし起動時の設定を決めるピンだが、液晶側は入力なので起動に影響しない。
    3V3 / GND / 5V各1本3V3 は液晶とジョイスティック、GND は6か所で使うので、まとめ点で分ける。
    液晶の初期化要確認INITR_BLACKTAB（main.cpp:2832）。色が反転したり端に線が出たら INITR_GREENTAB などに変える。
    シリアルログ使えないGPIO 43 を液晶の CS に使うため、USB シリアルは文字化けする。ログは Wi-Fi 接続後に http://（カメラのIP）/log で見る（main.cpp:208-210）。
    GPIO 48（フラッシュ）影響小基板上の RGB LED（WS2812）もつながっているので、フラッシュのたびにボードの LED も光ることがある。
    GPIO 2（ジョイスティック VRy）影響小基板上の LED もつながっていて、スティックを倒すと光ることがある。判定には影響しない見込み。
    うまく動かないとき参考カメラの初期化に失敗すると「CAM FAIL」と出て3秒後に再起動（main.cpp:2890-2895）。画面が白いままなら液晶の SCK / SDA / CS / DC / RST を見直す。

    05これからの進め方

    部品は 2026/11/20 に注文済み。届いた順に進める。

    時期届くものやること
    11/21ボード、テスター、LED、抵抗、ボタン、スイッチ、ジャンパー線、TP4056 / MT3608手順0。ボードだけ USB-C でつないで pio run -t upload。書き込みが通れば OK。付属の microSD を挿して、カメラのケーブルの向きも見ておく。
    12/818650 電池手順5〜7。電池ホルダーを TP4056 へ、スイッチと MT3608 をつなぐ。テスターで 5.0V に合わせる。ボードにはまだつながない。
    12/20〜25液晶、ジョイスティック手順1〜4 と 8。全部つないで電池で起動する。起動画面が出たら完成。
    そのあと—外側をどうするか決める。作者みたいに L 字金具とボルトで枠を組むのが手軽そう。

    決めていること

    • 線の色は、電源が赤、GND が黒、信号が緑。
    • 3V3 と GND はまとめ点で分ける。
    • 書き込みと充電のときは電源スイッチを切る。

    届いてから確かめること

    • 液晶の色やずれ。おかしければ INITR_BLACKTAB を INITR_GREENTAB などに変える。
    • 液晶にピンヘッダが付いているか。
    • 電池で動かして再起動するようなら、MT3608 の出力に 220〜470µF のコンデンサを足す。
